# Natha Foods shop

WooCommerce grocery shop for Natha Foods, Leipzig. German default, English second.

- `site/wp-content/themes/nathfoods/` is the custom theme.
- `demo/seed.php` sets up the German shop, the languages and a sample catalogue (fresh install only).
- `demo/blueprint.json` builds a WordPress Playground demo from `demo/nathfoods-theme.zip`. Rebuild the zip after theme changes.

Sample products, prices, photos and reviews are placeholders. Replace them before launch.

## Plugins

WooCommerce, Germanized, TranslatePress, WooCommerce Stripe Gateway, WooCommerce PayPal Payments, PDF Invoices & Packing Slips.
